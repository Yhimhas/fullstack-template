# 后端协作

先执行 [根 AGENTS.md](../AGENTS.md)。工程要求和技术选择查 [README.md](README.md)，Git 流程查 [根 README](../README.md)。本文件补充后端任务的执行步骤，不改变根规则。

## 1. 定位工程与影响范围

检查实际构建配置、源码和项目说明，确认工程状态；工具或外部服务是否可用，以实际检查为准。

定位本轮任务涉及的请求入口、处理逻辑和配置，核对现有行为及预期结果。技术要求以 README 为准，额外框架、存储和部署方案需要另行讨论。

完成条件：能指出实际相关文件和必要运行条件，未确认的前提明确列出。

## 2. 在现有工程内实施

沿用既有代码组织和配置方式。配置示例使用占位值，实际凭据不写入代码、文档或日志。

完成条件：改动与任务逐项对应，没有引入未经确认的工程方案或真实凭据。

## 3. 分别验证构建、启动与行为

从实际构建配置选择适用的检查和测试。需要运行服务时，先核对环境及外部服务，再检查启动结果。涉及接口的改动，实际调用并核对状态、数据及相关错误行为。

分别报告编译或构建结果、服务启动结果和接口验证结果。缺少运行条件时，说明阻塞与未验证项，不以其中一项成功代替其他结论。

完成条件：验证覆盖改动影响的行为，结论能够对应实际命令或请求；未执行项明确列出。

## 4. 交接结果

说明受影响的文件、验证结果和剩余问题。配置或运行方式发生变化时，同步 README 中的相关说明。

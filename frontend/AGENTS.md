# 前端协作

先执行 [根 AGENTS.md](../AGENTS.md)。工程要求和技术选择查 [README.md](README.md)，Git 流程查 [根 README](../README.md)。本文件补充前端任务的执行步骤，不改变根规则。

## 1. 定位工程与影响范围

检查实际的依赖清单、锁文件、脚本及源码，区分已初始化工程与只有说明文件的目录。

根据本轮任务定位相关页面、组件和请求代码，确认当前实现及预期行为。核对 README 中的推荐与强制要求，按已确认的选择工作。

完成条件：能指出需要改动的实际文件，并说明预期变化；缺少必要信息时先澄清。

## 2. 在现有工程内实施

沿用现有组件、模块和配置方式。

完成条件：改动与任务逐项对应，未夹带无关重构或技术替换。

## 3. 按影响验证

从项目实际脚本选择适用的检查、测试和构建命令。使用 TypeScript 时，核对是否有独立类型检查，不能仅凭构建成功断言类型检查通过。

页面或交互变化需检查实际显示和操作结果；请求变化需核对实际地址、状态与返回内容。按可用工具验证，缺少浏览器或运行条件时列明限制及待验证项。

完成条件：每项验证结论都有实际操作支持，未执行项明确列出。

## 4. 交接结果

说明受影响的文件、验证结果和剩余问题。工程用法发生变化时，同步 README 中的相关说明。
